# Onboarding topics

Ask in this order. Pick at most three questions per round from each topic, and skip questions the owner has already answered. Example wording is a starting point; adapt it to the conversation and to `notes_language`.

## 1. Profile → `self/profile.md`
- What do you do (roles, work and outside work) that ideas might relate to?
- Which skills do you want agents to rely on you for, and which do you want help with?
- Anything about your situation agents should know (time zone, devices you use)?

## 2. Goals → `self/goals.md`
- What are one to three things you want to achieve this quarter?
- And this year? Anything "someday"?
- Which matters most if they compete?

## 3. Values and trade-offs → `self/values.md`
- When speed and quality conflict, which wins by default?
- What would make you reject an otherwise good idea?

## 4. Preferences → `self/preferences.md` (or `ways/private/` if personal)
- How should agents write to you: short or detailed, formal or casual?
- When should questions wait rather than reach you right away?

## 5. Constraints → `self/constraints.md`
- How much time per week can you give to reviewing agent work?
- Budgets or limits (money, usage, tools) agents must respect?
- Things agents must never do?

## 6. Principles → `ways/public/principles.md` (copied into project repos)
- How small should a pull request be for you to review it comfortably on a phone?
- Tests: what must every change include?

## 7. Stack → `ways/public/stack.md`
- Languages, frameworks and tools you prefer, and versions if they matter?
- Anything you never want used?

## 8. Conventions and review → `ways/public/conventions.md`, `ways/public/review.md`
- Naming, commit message and documentation conventions you follow?
- What do you check first when you review a pull request?
