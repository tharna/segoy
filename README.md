# segoy

Segoy is a kit that turns Claude Code and GitHub into a personal idea-to-implementation pipeline: capture an idea on your phone, approve a plan, review a pull request.

- [docs/](docs/README.md) — product requirements, architecture, workflows, brain template, the Otak Android app spec, and the bootstrap plan.
- [design-system/](design-system/README.md) — the Segoy design system: a terminal-style, mobile-friendly interface language used by every Segoy UI.

Status: milestone M0 (foundations and spikes). The repo skeleton, skill linter and CI exist; nothing else in `docs/` is implemented yet. See [docs/bootstrap-plan.md](docs/bootstrap-plan.md).
