# Migration to 0.1.0

## Who needs this
Repos set up before `segoy sync` existed (versions `0.1.0-dev+…`): their kit was copied by hand, and some project repos have no `.segoy/manifest.json` at all.

## Steps
1. If the repo has no `.segoy/manifest.json`, run `scripts/segoy init project --ways <brain>/ways/public <repo>` (or `init brain`). Init never overwrites: existing files are reported as `skip`, and the manifest records what is there.
2. Run `scripts/segoy sync --dry-run <repo>` and read the report. Files that match any earlier kit version are reported as `update`, not as conflicts.
3. Merge the sync PR that the `kit-sync` task (or `scripts/segoy sync --pr <repo>`) opens.

## Check
`scripts/segoy doctor --offline <repo>` reports the kit version `0.1.0` and no missing kit files.
